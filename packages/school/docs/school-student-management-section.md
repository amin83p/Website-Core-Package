# School Student Management section

Dedicated workspace at `/school/student-management` (access section `SCHOOL_STUDENT_MANAGEMENT`, id `445587`), nested under the main **SCHOOL** dashboard.

Seed MongoDB section, symbol, parent link, and default `SCHOOL_STAFF` grants:

```bash
npm run school:student-management-section:seed
```

Use `--uri` or `MONGODB_URI` when not using the default `app` database name.
